# 📱 iOSMachineTest

A professional **iOS Machine Test application** built using **Swift and UIKit**.
This project demonstrates practical iOS development skills including UI implementation, API integration, JSON handling, navigation, and clean code organization.

## 🚀 Features

* 📱 Native iOS UI using UIKit
* 🎨 Responsive UI with Auto Layout
* 🌐 REST API integration
* 📦 JSON data handling
* 🔄 Dynamic data loading
* 🧭 Screen navigation
* 🧩 Reusable UI components
* ⚡ Clean and maintainable Swift code
* 🛠️ Error handling and debugging
* 📐 Storyboard/XIB based UI

## 🔧 Installation

### 1. Clone the repository

```bash
git clone https://github.com/anilyadavjnt/iOSMachineTest.git
```

### 2. Open the project

Open:

```text
iOSMachineTest.xcodeproj
```

in Xcode.

### 3. Select a Simulator

Choose an iPhone simulator from Xcode.

### 4. Build and Run

Press:

```text
⌘ + R
```

to build and run the application.
